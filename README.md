# Brand Guidelines
Style guides and assets for UWE Computer Science Society promotional materials.

## Proposed Repository Structure
- `./` root folder: README.md linking to various guides and rough explanation
- `Logo/` Logo in light/dark settings in SVG format, as well as PNG in various sizes (icon, sticker, large, etc.)
- `Social/` social media post templates in PSD format that can be easily modifieed to suit needs of an event (IG, LI, chatrooms). One for socials, one for community hour, one for tech talks, one for workshops, and some for special events when the time comes.
- `Print/` print media - posters, handouts, QR codes, etc.
- `Guides/` brand guidelines on colour, logo placement, web design (how to modify blog, write articles, etc.)
